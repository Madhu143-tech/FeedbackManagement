# Feedback Management MVC

## Open in Visual Studio 2022
1. Extract this ZIP.
2. Open `FeedbackManagementMVC.sln` in Visual Studio.
3. If prompted, restore NuGet packages.
4. Set `FeedbackManagementMVC` as the startup project if asked.
5. Press F5 or Ctrl+F5.

Requires the .NET SDK (supports .NET 10 / .NET 8) and the Visual Studio **ASP.NET and web development** workload.

The project uses in-memory sample data. New feedback resets when the application restarts. Bootstrap and client-side validation assets use CDNs.
